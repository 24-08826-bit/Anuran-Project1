<h3 align = "center">Project Description</h3>
<p align = "center">

This project is an Online Resume created using HTML. It is designed to present my personal information, education, work experience, skills, and achievements in a simple and organized webpage.

The project focuses only on HTML to practice the basic structure and elements of a website.

### Project Objectives
Create an online resume using HTML.
Practice using different HTML tags and elements.
Organize information into different sections.
Add a profile photo using HTML.
Create multiple pages using anchor tags.
Publish the website using GitHub Pages.

### Resume Sections

### The online resume includes:

Summary / Objective<br/>
